# OnePlus 9 日用 base 2026.10.30-base.1

此版本将此前的 K380 键盘适配、应用安装修复与现有 120 Hz、Metal、Wi-Fi、
电池、蓝牙和 Sileo 基线合并为同一个本机运行包。验收状态与文件哈希由包内
`manifest.json`、`VALIDATION.json` 和 `SHA256SUMS` 记录。

## 本轮改动

- 键盘输入桥接保持原生蓝牙配对、加密与 HID 协议，只补足缺失的键盘事件服务。
  K380 的实体按键、Shift、退格、方向键和切换设备后重连已在开发镜像实测；
  此版本集成对应组件，不扩展为所有蓝牙 HID 或音频设备支持。
- 注入配置在生成镜像前检查内核的 512 字节上限；附加验收库使用短路径，
  防止测试配置溢出导致所有兼容库失效。
- RAMFS 提供带版本与容量上限的显式临时挂载参数，默认数据盘仍为物理内存四分之一，
  受限临时区最多二分之一。该源码纳入内核构建复制与哈希校验。
- 开机离线恢复 TrollStore 2.1.1、TrollApps 2.3、Delta 1.7.1 和 B站 8.89.0。
  使用只读 System 镜像内的已校验安装包，不依赖临时 LAN 服务或在线下载。
  安装返回码、LaunchServices 版本及临时区卸载共同参与验收；完成后保留桌面。
  安装、等待子进程和清理全过程持有原生 XPC 活动事务，避免被当作空闲任务回收。
- TrollApps 首次打开保留已有源并加入选定的 7 个公开源。Delta 首次打开选择现有 Metal 路径，
  通过应用原有导入接口添加作者免费发布的 Vulkanon。
- CI 编译并打包键盘服务与适配库，公开组件包仍不包含 Apple 系统、手机固件、
  第三方应用安装包或设备标识。

原 System 镜像的 69,236 个条目已逐个核对内容、权限、属主和链接，
本轮离线应用镜像仅新增 10 个资源条目。根运行镜像包含 169 个条目。
源码、构建记录和每个最终文件均保留哈希，旧封存包继续保留。

## 验收

主机端 base 30 项、USB 63 项、公开打包 9 项测试通过；
蓝牙传输、解析与键盘生命周期的 ASan/UBSan 测试通过。
运行组件和内核已重新构建，内核构建流程将既有链接后导出列表告警与编译错误分开处理。

实机验收记录位于本机 `local/lemonade/release-2026.10.30-base.1/`，本次已通过：

- 对应内核的真实 DMA guard。
- 同一组镜像的联合验收：1450 帧直接显示、Metal 103 项、MPS 2 项、
  Core Animation 4 项、联网 61 项、电池对照、14 次蓝牙状态采样，
  以及所有离线应用恢复、正常退出和临时区卸载。
- 原生蓝牙设置中的受控 BLE 目标发现；保留来自真实显示提交的 IOSurface 录制，
  画面显示 `Lemonade Test`。这不是光学屏幕拍摄，也未重测实体键盘输入或配对。
- 未经扩展的正式镜像由包内启动器启动，持续观察 180 秒后主动退出。
  完成 252 帧直接显示，29 项检查全部通过，退出段错误计数为 0。
  没有测试任务、定时退出或自动应用切换，离线恢复与临时区卸载均完成。
- 返回 Android 后，设备、活动槽和锁状态与基线一致；五个活动启动分区哈希匹配原始备份。

未经通过的候选由启动器拒绝正常启动。若仅修改用户态，可用 `--reuse-guard`
重新校验同一内核的原始 DMA 故障日志与哈希；内核哈希不同会拒绝复用，联合验收仍重新运行。
活动事务使用 Apple 的 [xpc_transaction_begin/end 契约](https://developer.apple.com/documentation/xpc/xpc_transaction_begin())。

蓝牙发现验收同时检查原生设置页面、控制器状态和退出恢复。发现事件可以来自
经典蓝牙通知，也可以来自原生页面实际显示的受控 BLE 测试目标。
`devices/oneplus-9/tools/lemonade-bt-discovery-target.m` 使用 macOS CoreBluetooth
发送十分钟的 `Lemonade Test` 广播；观察程序仅记录此已知标签是否真实出现，
不输出其他设备名称。该路径仍要求页面处于前台且存在设备行，不以广播启动成功
或控制器在线代替手机发现证据。测试目标没有键盘数据、GATT 服务或配对操作，
因此不作为键盘输入或蓝牙音频的验收。

## 使用和已知限制

本机包的 `Start.command` 从 Android 冷启动到 HackiOS；
`Return-to-Android.command` 正常退出并恢复 Android 蓝牙设置。
全程使用 `fastboot boot` 和 RAM，`ufs_write=0`、`var_store=0`，不刷写 Android 分区。
重启会重新恢复所选应用包，账号、设置、游戏存档和其他个人数据仍不保留。
包内没有 Wi-Fi 密码、配对记录或账号数据，默认不自动打开应用或运行游戏，
不包含测试程序、自动手势、截图回传、线程采样或定时退出。

Delta 已验证安装、打开游戏库和导入 Vulkanon。原生游戏页可出现，
但未取得游戏首帧；显式重试进入 `AudioManager.resetAudioEngine` 后触发 SIGTRAP，
同段日志显示系统音频会话服务不可用。游戏可玩性、声音和后续渲染仍待完善。
B站已验证安装与进程启动，登录、视频播放和声音未验收。
这是当前功能基线，不能视为所有 iOS 应用兼容或完整手机系统。
详见 [应用实测记录](LEMONADE-TROLLAPPS.md) 和 [蓝牙实测记录](LEMONADE-BLUETOOTH.md)。

该完整运行包包含本机系统和固件材料，仅留本机使用；Git 只提交源码与文档。
